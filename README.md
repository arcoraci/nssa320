# NSSA320 Configuration Management Lab Files

This repository contains supporting files for **NSSA320 – Configuration Management**. The materials in this repository are used for course labs and activities focused on infrastructure automation, configuration management, and repeatable system deployment.

The primary tools used in this repository are:

- Terraform for infrastructure provisioning
- Ansible for configuration management and automation
- Supporting scripts, templates, and example files as needed for lab activities

## Repository Purpose

This repository is intended to provide students with the files needed to complete NSSA320 lab assignments. These files may include Terraform configuration files, Ansible playbooks, inventory files, variable files, templates, and other supporting resources.

Students should use this repository as a starting point for course labs and follow the specific instructions provided in myCourses for each assignment.
